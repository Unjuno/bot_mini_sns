# Lean 4形式証明

`FixedFlow.lean` は本体MVPの固定フローを形式化し、Lean 4で次の性質を証明します。

**証明済み（定理あり）：**
- 最初の文章・写真は保存され、使い方を返す
- 2回目以降の文章は保存される
- 2回目以降の写真は保存される
- 保存後は最近の投稿を返信する

**型定義済み・未証明：**
- 音声・動画・ファイルの入出力（型・遷移関数は実装済み、定理は未追加）

全5種（文章・写真・音声・動画・ファイル）に対して同じ固定フローが定義されています。

実行例：

```powershell
lean formal/FixedFlow.lean
```
