# Matrix / Element

調査日：2026年7月26日

## 料金

MatrixプロトコルのAPI利用料はない。matrix.orgの無料枠または他社ホスティングを使えるが、自前Homeserverではサーバー・ストレージ費用が必要。

## 使い方

HomeserverへBotユーザーを登録し、Matrix Client-Server APIまたはSDKでSyncしてイベントを受信する。返信は同じルームへイベントとして送る。

## ADKomeとの適合

自由度とデータ管理に強い。文章・メディアを扱えるが、Homeserver選択と運用が必要で、初期実装の優先度は低い。
