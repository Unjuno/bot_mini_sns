# Zulip

調査日：2026年7月26日

## 料金

Cloud Freeは検索履歴10,000件・ファイル5GB。Standardは年払いで1ユーザー月6.67ドル、月払いで8ドル。セルフホスト版はオープンソースだがサーバー費用が必要。無料Standardは対象組織に限られる。

## 使い方

Zulip組織へBotを追加し、Interactive Bots APIやWebhookでDM・メンションを受信する。Send Message APIで返信する。

## ADKomeとの適合

話題単位のコミュニティに向く。文章・ファイル・メディアの共有に対応するが、単純な個人タイムラインにはやや過剰。
