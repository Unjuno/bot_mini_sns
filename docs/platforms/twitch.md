# Twitch Chat

調査日：2026年7月26日

## 料金

Bot API・EventSubの一律利用料は基本的にない。Botを動かすサーバー費用と、認証・利用制限が別途必要。

## 使い方

Twitchアプリを登録し、EventSubでチャットメッセージを受信する。Twitch APIまたはIRCでチャットへ返信する。配信者の認可とスコープが必要。

## ADKomeとの適合

配信チャット向けであり、画像・音声・動画・ファイルの投稿SNSには向かない。チャット保存用途が必要な場合だけ検討する。
