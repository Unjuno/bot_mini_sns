# Misskey

調査日：2026年7月26日

## 料金

API利用料は基本的にない。既存インスタンスの利用条件、または自前インスタンスのサーバー・ストレージ費用が必要。

## 使い方

対象インスタンスでアクセストークンを作成し、Notes APIで投稿・返信する。Streaming APIでノートや通知を受信する。インスタンスごとの設定差を確認する。

## ADKomeとの適合

SNS・タイムライン型で相性が良い。文章・メディア・返信を扱えるが、チャットBotではなくSNSアダプターとして設計する。
