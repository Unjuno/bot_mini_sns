# Slack

調査日：2026年7月26日

## 料金

Freeプランで開発できる。Freeはメッセージ履歴90日などの制限があり、Pro以上は有料。API利用とWorkspace契約は分けて確認する。

## 使い方

Slack Appを作成し、Event Subscriptionsでイベントを受信する。Bot Tokenでメッセージやファイルを送信する。チャンネル参加と権限設定が必要。

## ADKomeとの適合

文章・添付を扱えるが、チーム内利用向け。一般ユーザー向けSNSの入口としては優先度を下げる。
